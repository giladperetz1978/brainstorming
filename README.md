# סיעור מוחות (Brainstorming) 🧠⚡

אפליקציה חכמה לסיעור מוחות מסביב לשולחן עגול עם **Gemini 3.8 Flash** וחיבור מוצפן מלא:
- משתתף אנושי (עם שם הניתן לעריכה ישירה על השולחן).
- ארבעה סוכני AI בעלי אופי וזווית ראייה ייחודית (מאיה החיובית, אורי המתנגד, תמר האופטימית, לוי הפסימי).
- מחקר רשת מבוסס AI לפני הסיעור, רעיונות ודיון חי סביב כל רעיון.
- מותאמת במלואה למחשב ולסמארטפונים.
- **אבטחה והצפנה**: תקשורת מוצפנת ב-TLS/HTTPS ואחסון מוצפן (AES-GCM 256-bit בדפדפן, DPAPI מקומי ב-Electron).

## גרסת דפדפן ו-GitHub Pages

האפליקציה נבנית ונפרסת אוטומטית ל-GitHub Pages באמצעות GitHub Actions:
- **כתובת האתר**: `https://giladperetz1978.github.io/brainstorming/`
- בגרסת הדפדפן (כולל בטלפון הנייד) ניתן ללחוץ על גלגל השיניים ⚙ ולהזין מפתח Gemini API אישי הנשמר מוצפן בדפדפן.

המפתח אינו נכלל בקוד, ב-build או ב-GitHub Actions. יש להזין אותו באתר פעם אחת לכל דפדפן ומכשיר; אחסון האתר ב-GitHub Pages נפרד מהאחסון ב-localhost ומ-Electron. לאחר שמירה מוצלחת החיבור משוחזר ברענון. ניקוי נתוני האתר מוחק גם את המפתח השמור.

אם אימות המפתח, ההצפנה או האחסון נכשלים, הממשק מציג שגיאה במקום להכריז על הצלחה. בדפדפן ההצפנה המקומית אינה כספת בפני קוד שרץ באותו origin או משתמש עם גישה לפרופיל הדפדפן: חומר גזירת המפתח נמצא בקוד הלקוח. ב-Windows גרסת Electron משתמשת ב-safeStorage ובהגנת מערכת ההפעלה. אין להכניס מפתח משותף לסודות build או לקוד frontend ציבורי.

## הפעלה מקומית בשולחן העבודה (Electron)

פותחים טרמינל בתיקיית הפרויקט ומריצים:

```powershell
npm run app
```

הפקודה עושה הכול:
1. מבקשת את Gemini API key בקלט מוסתר (התווים לא מוצגים על המסך).
2. בונה את ה-frontend.
3. פותחת חלון Electron עם frontend ו-backend מקומיים.

## פיתוח

### חדר השיחה התלת־ממדי

- חדר Three.js עם חמש דמויות, סיבוב מצלמה בגרירה או במגע, זום, מבט־על ומבט מכיוון מושב המנחה.
- סיבוב אוטומטי ניתן לעצירה; בחירת משתתף ממקדת בו את המצלמה ומגדירה אותו כנמען השיחה. בחירת "כולם" מחזירה שיחה עם ארבעת הסוכנים.
- אפשר להתחיל שיחה כתובה מיד, ללא יצירת רעיונות מראש. היסטוריית הדיון משותפת ונשלחת כהקשר גם במעבר בין נמענים.
- "התחל סיעור" משתמש במחקר וביצירת הרעיונות הקיימים. לשוניות השיחה, הרעיונות והמחקר זמינות לצד החדר, או מתחתיו בנייד.
- Enter שולח הודעה; Shift+Enter מוסיף שורה. הגדרות Gemini נפתחות בגלגל השיניים. מפתח תקין נדרש לפעולות AI, אך לא לתנועה בחדר ולהוספת רעיון אישי.
- השיחה היא טקסטואלית. אין בשלב זה זיהוי דיבור, קול לסוכנים או סנכרון שפתיים; אנימציית הדמויות אינה סימולציה של דיבור קולי.
- התנועה האוטומטית כבויה כברירת מחדל למי שהגדיר הפחתת תנועה במערכת. כש-WebGL אינו זמין, השיחה והרעיונות נשארים נגישים.
- הנתונים נשארים בזיכרון הסשן כפי שהיה קודם; רענון הדף מאפס את השיחה. סבב חדש מחליף את הרעיונות ואת הדיון הקודם.
