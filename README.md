# סיעור מוחות (Brainstorming) 🧠⚡

אפליקציה חכמה לסיעור מוחות מסביב לשולחן עגול: משתתף אנושי (עם שם הניתן לעריכה), ארבעה סוכני AI בעלי אופי וזווית ראייה ייחודית (מאיה, אורי, תמר, לוי), מחקר רשת בזמן אמת, רעיונות ודיון אינטראקטיבי.
מותאמת במלואה גם למחשב וגם לסמארטפונים.

## גרסת דפדפן ו-GitHub Pages

האפליקציה נבנית ונפרסת אוטומטית ל-GitHub Pages באמצעות GitHub Actions:
- **כתובת האתר**: `https://giladperetz1978.github.io/brainstorming/`
- בגרסת הדפדפן (כולל בטלפון הנייד) ניתן ללחוץ על גלגל השיניים ⚙ ולהזין מפתח Gemini API אישי הנשמר מקומית בדפדפן.

## הפעלה מקומית בשולחן העבודה (Electron)

פותחים טרמינל בתיקיית הפרויקט ומריצים:

```powershell
npm run app
```

הפקודה עושה הכול:
1. מבקשת את Gemini API key בקלט מוסתר (התווים לא מוצגים על המסך).
2. בונה את ה-frontend.
3. פותחת חלון Electron עם frontend ו-backend מקומיים.

## פיתוח

```powershell
npm install
npm run build
npm run lint
npm run dev
```
